## MusicHub v1.0.0

Windows 桌面音乐播放器：本地曲库 + 多平台插件化在线音源。

### 这个版本包含

- **本地曲库**：扫描 MP3 / FLAC 等格式，读取标签、封面、歌词；支持歌名 / 歌手 / 专辑 / 歌词全文模糊搜索
- **播放器**：单击预览、双击播放、进度拖动、音量、顺序 / 单曲 / 随机、歌词页、队列
- **在线音源**：网易云、QQ 音乐、酷狗（可扩展），多音源并行搜索、播放换源兜底、在线预览与收藏
- **账号登录**：打开平台官方登录页，登录后可读私人歌单、播放会员曲目
- **歌单**：自建歌单增删改查、拖拽排序、平台歌单导入、我喜欢（本地与在线混排）
- **下载**：队列与进度、取消重试、风险确认弹窗、随音频保存封面、自定义下载目录

### 安装

- `MusicHub-1.0.0-Setup.exe`：安装版（可选安装目录，创建桌面快捷方式）
- `MusicHub-1.0.0-Portable.exe`：便携版，免安装直接运行

系统要求：Windows 10 / 11 x64。未做代码签名，首次运行时 SmartScreen 可能提示，选择"更多信息 → 仍要运行"即可。

### 已知限制

- VIP 曲目能否播放取决于登录账号的会员状态
- QQ 音乐的「我喜欢」请从导入面板的列表中点选，直接填 `201` 无效
- 酷狗仅支持搜索（播放需要平台签名算法）
- 仅支持 Windows
